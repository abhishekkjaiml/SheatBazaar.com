# 🛍️ SheatBazaar - E-Commerce Website

An e-commerce website built with **HTML**, **CSS**, and **JavaScript**, featuring product browsing, category navigation, shopping cart functionality, dynamic price updates, and a clean, user-friendly interface. The project uses **dummy product data** to demonstrate core e-commerce functionality without a backend.

# 📖 Overview

SheatBazaar is a frontend-only e-commerce website developed using **HTML**, **CSS**, and **JavaScript**. It simulates an online shopping experience using **dummy product data**, allowing users to browse products, explore categories, add items to the shopping cart, and dynamically update cart totals.

This project focuses on JavaScript fundamentals, DOM manipulation, and building an interactive shopping interface without any backend or database.

```bash

```

## Navigate to Project

```bash

```

## Run the Project

Open **Index.html** in your browser

Use the **Live Server** extension in Visual Studio Code.
